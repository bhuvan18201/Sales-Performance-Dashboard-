# 📊 Sales Performance Dashboard (Power BI)

## Overview
This repository contains a Power BI dashboard that provides a comprehensive analysis of business sales performance. It is designed to help stakeholders monitor key metrics, identify top-performing categories, and gain insights into regional and customer segment trends.

## Features
- **Key Metrics Summary**
  - Total Sales: 2.3M
  - Quantity Sold: 38K
  - Profit/Loss: 286K
  - Discounts: 1.56K
  - Customer Count: 793

- **Visual Insights**
  - Sales by Subcategory (Phones, Chairs, Storage, etc.)
  - Sales by Region (West, East, Central, South)
  - Sales by Category (Furniture, Office Supplies, Technology)
  - Sales by Segment (Consumer, Corporate, Home Office)
  - Geographic distribution of sales by state

## Purpose
The dashboard enables:
- Quick identification of high-performing product categories and regions
- Monitoring of profitability and discount strategies
- Customer segmentation analysis for targeted business decisions
